Poses are stored as angles only — swing, spread and twist per joint, never positions — which is what lets one authored clip play on a Bulwark and a Dual mage without being redrawn. Everything here runs the same forward kinematics the game does, off the same table in crates/view/src/baked.rs. Frame numbers, phase boundaries and clip lengths come from the move table, so retuning a move in the Oven moves its animation with it.
