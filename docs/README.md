## Notes on the conversion

- Wording is preserved from the source documents. Changes are formatting only:
  Drive's nested bullets became standard Markdown lists, headings were promoted
  from the documents' own section titles, and definition-style bullets
  (`Name - description`) use bold for the name.
- Two documents are both titled "General information" — one under Combat design,
  one under World. The folder structure keeps them apart.
- Several documents trail off mid-thought or have empty sections. Those are
  marked in place rather than silently dropped.
