Arena — prototype

Rollback arena fighter, mid-build. One player and a training dummy.

This wants a keyboard and a mouse

It is a third-person fighter: WASD to move, and the mouse to aim. There is no touch control, and the build is a good few megabytes.

Loading the arena

Fetching the build. It is a few megabytes and it is cached after the first time.

Click to capture the mouse · Esc to release

  


  

    Six classes. Tab cycles yours, F8 shows the pickers, 1–4 sets what the dummy does.
    
  


  

    Everything you press is simulated in fixed point and nothing about the fight
    is decided by the renderer — the same build plays peer-to-peer on a desktop
    with rollback netcode. A browser cannot open a UDP socket, so this
    page is single player: you, and a dummy you can set to stand still, block,
    or attack on a cadence you can practise parrying.
