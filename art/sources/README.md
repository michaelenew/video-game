# Sources

Meshes made by other people that a character is built from, each with where
it came from and its licence.

| File | What | From | Licence |
| --- | --- | --- | --- |
| `human_base_mesh_male.npz` | The realistic male body: the dark being's body (`art/dark_being`, `lib/base_mesh.py`) | *Human Base Meshes* v1.0 by Blender Studio, the `GEO-body_male_realistic` object, its sculpt folded into the base mesh by `extract_human_base_mesh.py` | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

The bundle itself is not kept here (61 MB): it is Blender Studio's, from
blender.org's demo files, and archived at
<https://archive.org/details/human-base-meshes-bundle-v1.0.0>. Re-extract with

    art/blender.sh art/sources/extract_human_base_mesh.py path/to/human_base_meshes_bundle.blend

CC0 asks for no credit; it is given anyway.
